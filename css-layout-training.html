Module 1 of 5

The Box Model

Every element on a web page is a rectangular box. That box is made of four layers, from the inside out: content, padding, border, and margin. Understanding these four layers is the base for everything else in CSS layout.

.box {
  /* CONTENT: the size of the box's inner area */
  width: 200px;
  height: 100px;

  /* PADDING: space inside the border, around the content.
     Padding is the same colour as the box - it just adds room. */
  padding: 20px;

  /* BORDER: a visible line between the padding and the margin.
     Format is: thickness style colour */
  border: 3px solid #648000;

  /* MARGIN: space outside the border, between this box
     and the elements next to it. Margin is always see-through. */
  margin: 15px;

  /* box-sizing changes how width/height are worked out.
     This is the setting that confuses most beginners. */
  box-sizing: content-box; /* default: width is CONTENT only,
     so padding and border are added on TOP, making the box bigger */
  /* box-sizing: border-box;  <- width would then be the TOTAL
     box size (content + padding + border together) */
}
Try this:
  1. Move the padding and border sliders up as high as they go.
  2. Switch from content-box to border-box and watch the total box size stop growing.
  3. Write down, in your own words, what box-sizing controls.

Module 2 of 5

The display Property

display controls how an element behaves in the page: whether it starts on its own line, whether it accepts a width and height, and how it sits next to other elements.

/* BLOCK: starts a new line, stretches to fill the parent's width,
   and accepts width/height/margin on all sides.
   Default for: div, p, h1, section */
.block-example { display: block; width: 150px; height: 60px; }

/* INLINE: flows inside a line of text, only as wide as its content.
   Default for: span, a, strong */
.inline-example {
  display: inline;
  width: 150px;   /* IGNORED by the browser */
  height: 60px;    /* IGNORED by the browser */
}

/* INLINE-BLOCK: sits in a line like inline, but respects
   width/height/margin like block. The best of both. */
.inline-block-example { display: inline-block; width: 150px; height: 60px; }
Try this:
  1. Switch to inline and notice the width/height stop having any effect.
  2. Switch to inline-block and see the width/height come back, while boxes still sit side by side.

Module 3 of 5

The position Property

position changes what an element is measured from, and whether it stays in the normal flow of the page. There are five values: static, relative, absolute, fixed, and sticky.

/* STATIC: the default. Sits in normal flow. top/left/right/bottom do nothing. */
.static-example { position: static; }

/* RELATIVE: stays in normal flow, but can be nudged from where it
   WOULD normally sit. The empty space it leaves behind does not close up. */
.relative-example { position: relative; top: 15px; left: 20px; }

/* ABSOLUTE: removed from flow completely. Positioned against the
   nearest ANCESTOR that has position set to anything but static.
   If no ancestor qualifies, it positions against the whole page. */
.parent { position: relative; } /* this makes .parent the anchor */
.absolute-example { position: absolute; top: 10px; right: 10px; }

/* FIXED: removed from flow, positioned against the BROWSER WINDOW,
   and stays there even when the page scrolls. */
.fixed-example { position: fixed; bottom: 20px; right: 20px; }

/* STICKY: acts like relative until a scroll threshold is reached,
   then sticks like fixed, within its parent container. */
.sticky-example { position: sticky; top: 0; }

Module 4 of 5

Flexbox

Flexbox arranges items in a single row or column, and shares out space between them without manual pixel maths. It has properties for the container (the parent) and properties for the items (the children).

.flex-container {
  display: flex;   /* turns on flexbox for direct children */

  /* which direction items flow along */
  flex-direction: row;   /* or: row-reverse, column, column-reverse */

  /* spacing along the MAIN axis (the direction set above) */
  justify-content: flex-start;  /* or: center, space-between, space-around */

  /* alignment on the CROSS axis (perpendicular to the main axis) */
  align-items: stretch;   /* or: center, flex-start, flex-end */

  flex-wrap: nowrap;   /* or: wrap, to let items drop to a new line */
  gap: 12px;    /* spacing between items */
}

.flex-item {
  /* how much this item grows to fill leftover space, compared to others */
  flex-grow: 1;
}
Try this:
  1. Change flex-direction to column and notice justify-content and align-items swap which direction they control.
  2. Set justify-content to space-between - this is the most common real-world flexbox pattern.
  3. Set Box Two's flex-grow to 3 and watch it eat up the leftover space.

Module 5 of 5

CSS Grid

Grid arranges items in rows and columns together, at the same time. Use it for a whole page layout - header, sidebar, main content, footer - or for anything genuinely two-dimensional, like a photo gallery.

.grid-container {
  display: grid;
  /* one column per value: 200px fixed, then two equal
     "fr" (fraction of leftover space) columns */
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: 80px auto 60px;
  gap: 16px;
}

.sidebar {
  /* grid lines are numbered from 1. This spans row lines 1 to 3,
     meaning it covers rows 1 AND 2. */
  grid-row: 1 / 3;
}
.header {
  /* spans column lines 2 to 4, meaning columns 2 AND 3 */
  grid-column: 2 / 4;
}

/* A responsive grid with no media queries needed: */
.auto-responsive-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 16px;
}
Try this:
  1. Switch the sidebar from Left to Right and notice only the sidebar/main column numbers swap.
  2. Compare sidebar width 1fr against a fixed 160px.
  3. Write one sentence explaining, in your own words, the difference between Flexbox and Grid.
